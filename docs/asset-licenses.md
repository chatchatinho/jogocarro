# Licenças de assets

Todo asset externo usado no projeto (fonte, imagem, som, música) é registrado aqui antes
de entrar no jogo.

| Asset | Arquivo | Fornecedor | Licença | Uso |
|---|---|---|---|---|
| Fonte Press Start 2P | `assets/fonts/PressStart2P-Regular.ttf` | Google Fonts (fonts.gstatic.com) | SIL Open Font License 1.1 (livre para uso comercial e redistribuição) | Fonte do HUD e dos textos do jogo, para o visual 16-bit |

Nenhum outro asset externo (modelo 3D, textura, som) foi usado — a pista, os carros e todo
o resto do visual são gerados por código (`scripts/Track.gd`, `scripts/Car.gd`).
